# АПУВИР «Большая Медведица» — Платформа Ассоциации

Веб-платформа Ассоциации профессиональных участников венчурного и инвестиционного рынка «Большая Медведица».

Платформа объединяет официальный портал ассоциации, агрегатор инвестиционных мероприятий и событий рынка РФ, новостной модуль, движок парсинга/ингеста с валидацией через Google Gemini, и панель модерации/управления.

---

## Ключевые возможности

1. **Официальный лендинг Ассоциации**:
   - 1:1 перенос контента с `https://ursa-major.ru` в чистом светлом дизайне (`#ffffff`, `#1a2e35`, фирменный акцент `#f8173f`).
   - Астрономически корректная интерактивная графика созвездия Большая Медведица (7 звезд Большого Ковша + Алькор + визирный луч на Полярную Звезду).
   - Блоки: Цели, Планы/Roadmap, Продукты, Резиденты (СОБА, Syndicate, Сколково и др.), Преимущества, Правление (Александрова, Заворин), Форма вступления.

2. **Каталог мероприятий (`/events` & `#events`)**:
   - Сетка карточек с категориями (Pitch Day, Демо-день, Конференция, Митап, Вебинар, Нетворкинг).
   - Фильтры по формату (Онлайн, Офлайн, Гибрид), городу, поиску и датам.
   - Модальное окно деталей события + выделенные SEO-страницы `/events/[id]`.
   - Кнопка «Подать мероприятие» с валидацией формы.

3. **Модуль новостей рынка (`/news` & `#news`)**:
   - Агрегация новостей инвестиционного и венчурного рынка РФ.
   - Статические страницы новостей `/news/[id]` с метаданными OpenGraph.

4. **Движок парсинга и ингеста (`/api/admin/ingest`)**:
   - Автоматический сбор событий из Telegram-каналов, пабликов и сайтов партнеров.
   - Структурирование и валидация через Gemini Flash.
   - Нормализация дат, гео-локаций и ссылок на регистрацию.

5. **Панель модерации и администрирования (`/admin`)**:
   - Вход по паролю (`/login`).
   - Управление источниками парсинга (Seeds Manager).
   - Очередь модерации: одобрение, отклонение, редактирование событий.
   - Ручной запуск цикла парсинга в реальном времени.

## Стек технологий

- **Фреймворк**: Next.js 15 (App Router, React 19)
- **Стилизация**: Tailwind CSS, Lucide Icons
- **База данных / ORM**: SQLite / Drizzle ORM
- **Тестирование**: Playwright E2E Suite
- **AI Интеграция**: Gemini Flash API для структурирования анонсов

---

## Запуск проекта

### Локальная разработка
```bash
npm install
npm run dev
```
Открыть [http://localhost:3000](http://localhost:3000).

### Сборка и запуск продакшн
```bash
npm run build
npm run start
```

### Запуск E2E тестов
```bash
npx playwright test
```
